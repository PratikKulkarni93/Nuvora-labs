# Go-live checklist
1. Replace placeholders: project list (PROJECTS in js/main.js), prices and text in index.html, email address, booking link (cal.com), team and testimonials.
2. Contact form: create a free form endpoint (Formspree, Web3Forms or similar) and paste its URL into FORM_ENDPOINT in js/main.js.
3. Upload this folder to Netlify, Vercel, Cloudflare Pages or any web host. No build step.
4. Point your domain at the host and enable HTTPS.
5. Add a 1200x630 share image and reference it in an og:image meta tag.
